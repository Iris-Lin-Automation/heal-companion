# 演示与宣传素材

## 现成可点

- 线上：https://heal-companion.onrender.com
- 立绘：`web/public/images/heal-character-main.jpg`（已嵌在 README）
- 雨声：进入对话后，顶部「···」→ 音乐 →「树荫下的雨声 / 热带雨林雨声」

## 要不要自己录视频？

| 方式 | 谁做 | 效果 |
|------|------|------|
| README 立绘 + 演示链接 | 已做好 | 招聘方 / 合作方 10 秒能看懂 |
| 30–60 秒手机录屏 | 你本地录最方便 | 适合发小红书 / 朋友圈拉人来玩 |
| 精剪宣传片 | 非必须 | 求职阶段收益低于「能点开的演示」 |

**建议：** 先靠链接拉人试用；若要视频，用手机录「登录 → 开雨声 → 说一句话 → 打开记忆本」即可，不必精剪。把 mp4 放到本目录命名 `demo.mp4` 后，可在 README 里加：

```markdown
[演示视频](docs/demo.mp4)
```

GitHub 对较大视频有体积限制；也可上传到 B 站 / 小红书，README 只放链接。
